# ASBFM — A Sakum Brothers Facility Management Pvt. Ltd.

A responsive corporate website for **A Sakum Brothers Facility Management Pvt. Ltd. (ASBFM)**, showcasing the company's facility management services and business information.

## 🌐 Live Website

**Website:** https://asbfm.in/

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS3
- **Language:** JavaScript
- **Version Control:** Git and GitHub

## ✨ Key Features

- Responsive layout for desktop, tablet, and mobile devices
- Corporate branding and company information
- Facility management services presentation
- Reusable React components
- Custom styling and responsive design
- Optimized frontend assets

## 💻 Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/saiteja-2230/asbfm-facility-management-website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd asbfm-facility-management-website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Production Build

To generate the production build, run:

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
